# Technical research

## Target and toolchain

Steam app 264710's public branch reported depot build **20241558**. The October 3, 2025 announcement describes an engine security hotfix. The latest official public modding contract available during this work was `Subnautica.GameLibs 82304.0.0-r.0`, which corresponds to the August 2025 patch. The October game's exact managed assemblies were unavailable in the cloud. This limits evidence for implementation bodies, scene prefabs, and live behavior. The local build accepts the installed game's managed assemblies for an additional API check. [Steam news](https://store.steampowered.com/news/app/264710/view/507340830949770983) · [Steam branch metadata](https://api.steamcmd.net/v1/info/264710) · [Official reference feed](https://nuget.bepinex.dev/v3/package/subnautica.gamelibs/index.json)

The inspected `Subnautica.Templates 1.1.1` package contains `snmod_nautilus` and sets .NET Framework 4.7.2, C# 11, BepInEx 5.4.21, Unity 2019.4.36 modules, Unity Input System 1.4.1, and GameLibs 82304.0.0-r.0. This project uses those build targets and pins Nautilus pre.57 and the test dependencies. The cloud .NET SDK was 10.0.404. [Template package](https://www.nuget.org/packages/Subnautica.Templates/1.1.1) · [Nautilus development guide](https://github.com/SubnauticaModding/Nautilus/blob/master/Nautilus/Documentation/guides/dev-setup.md) · [Nautilus pre.57 tag](https://github.com/SubnauticaModding/Nautilus/tree/5ef106c9586b1e73c519242f5354cb98ef754cb3)

## Verified API surface

| Area | Verified reference metadata or source | Smart Beacons integration |
|---|---|---|
| HUD lifecycle | `uGUI_Pings` declares `ManagedUpdate.Queue.PreCanvasPing`, a prefab pool, `IsVisibleNow()`, and a private `Dictionary<string, uGUI_Ping> pings`. `ManagedUpdate.Subscribe` and `Unsubscribe` are public. `PingManager.onRemove` is public. | Restore presentation in `PreCanvasFirst` and apply it in `PreCanvasTooltip` after the ping queue. Find the active ping HUD from the ping queue's subscribers and discard removed markers when the game raises its removal event. |
| Label, icon, scale, and color | `uGUI_Ping` exposes an `uGUI_Icon`, arrow graphic, name, distance and suffix TMP components, `SetIconAlpha(float)`, `SetTextAlpha(float)`, `GetTextAlpha()`, and its rect. The reference also defines the private `Color _iconColor` field. Beacon Color Picker calls `SetColor` after addition and on color changes. Easy Markers patches `UpdateText()`. | Read existing views and keep their sprites, RGB, fonts, and text. Change icon scale relative to its current game-provided transform and restore the baseline before vanilla's next update. |
| Discovery and visibility | `PingManager.Get(string)` resolves a registered `PingInstance`. The instance has `Initialized`, `visible`, `origin`, `GetPosition()`, and the separate `displayPingInManager` field. `visible`, `colorIndex`, and `_id` have protobuf field metadata. | Require an active, drawable vanilla view and a visible, initialized ping. The PDA filter is separate from HUD availability. Store the existing serialized navigation id and verify that it matches the HUD dictionary key before toggling priority. |
| Category | `PingType` includes Beacon, Lifepod, Seamoth, Exosuit, Cyclops, MapRoomCamera, Signal, Sunbeam, Rocket, Base, and ControlRoom. Nautilus can register additional types. | Group Signal, Sunbeam and Rocket under Story. Keep unrecognized and unclassified types in Other, with both categories Vanilla by default. Individual story signal classifications beyond these enum values remain unverified. |
| Camera and context | `MainCamera.camera`, `Player.GetVehicle()`, `currentSub`, `currentEscapePod`, and `SubRoot.isBase` / `isCyclops` exist. | Use the camera's viewing direction, normalized viewport and the already-rendered icon's screen position. Use explicit player context for additional fading and preserve vehicle signal prominence under the optional vehicle context modifier. |
| PDA | `uGUI_PingTab` has `SetEntriesVisibility(bool)`, `visibilityToggle`, and row selection logic. `uGUI_PingEntry.Initialize(string, bool, PingType, string, int)`, `UpdateLabel(PingType, string)` and `GetSelectables(List<ISelectable>)` exist. Easy Markers and Beacon Color Picker hook row creation. | Leave the existing bulk visibility control, color UI and controller selection intact. Use a native action for priorities while looking at a marker. A new row widget or filter needs live layout and controller verification. |
| Input and saves | Nautilus pre.57 provides native custom actions and bindable controls plus early-load, save, and quit callbacks. Its own `SaveDataCache` reads from the game's temporary save path during an early-load task. Unity Input System 1.4.1 provides the button action polling API used by the adapter. | Mod Input stores the bindings. Smart Beacons polls two Unity actions built from the nonconflicting keyboard and controller paths. Priority data uses a small validated sidecar in the save workspace and atomic replacement before vanilla saving continues. |

Reference bodies are stripped. Projected positions, the shape of the stock HUD prefab, alpha setter semantics and HUD transitions between normal play, vehicles, camera drones, and PDA menus still need the manual checks. The implementation checks visibility after the original call and retains both instance and Unity visibility checks even during quick reveal. It never invokes beacon registration, world positioning, discovery, or the vanilla visibility setter. [Nautilus source](https://github.com/SubnauticaModding/Nautilus/tree/5ef106c9586b1e73c519242f5354cb98ef754cb3/Nautilus) · [Easy Markers source](https://github.com/appendixis/Subnautica-EasyMarkers-Mod/blob/4bfc77582ebbfd704b8e5d71492318b2651e3aba/EasyMarkers/Patcher.cs) · [Beacon Color Picker source](https://github.com/shikyo13/SubnauticaMods/blob/022f74be25dbacac66906da7bbd04cf7b4343524/BeaconColorPicker/Patches.cs)

On Subnautica 1.22.83031 with BepInEx 5.4.23.5, the initial smoke test hit an unmarked IL label while Harmony was compiling the patch for `uGUI_Pings.UpdatePings`. Alpha.4 schedules its own callbacks around the vanilla ping queue. SubmersedVR provides an example of subscribing to the same pre-canvas scheduler. ## Vortex archive

Subnautica Support v3.3.3's BepInEx plugin installer identifies DLLs beneath `plugins`, removes the leading path through that directory, and deploys the remaining relative path to `BepInEx/plugins`. The archive contains exactly `BepInEx/plugins/SmartBeacons/SmartBeacons.dll`. The same ZIP can be extracted into the game root for manual installation. This layout was verified against source. Vortex itself was unavailable on the cloud runner.
